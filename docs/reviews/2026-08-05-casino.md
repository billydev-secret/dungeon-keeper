## Architecture — clean bill

- Money flow verified end-to-end through the economy funnel: `take_stake`
  is an atomic conditional daily-cap increment → `apply_debit` → cap
  rollback if the debit fails (an unaffordable bet doesn't eat cap);
  `refund` returns cap headroom with day-roll awareness; `pay_out` credits
  with `booster=False` so house payouts can never mint through the booster.
  This is the most defensively-written money code in the repo.
- Jackpot: skim-from-lost-stakes escrow (`jackpot_cut_pct`), seeded pot,
  standing balance reported netted in the tuning report (verified in the
  loose-ends run). Consistent.
- RNG is stdlib `random` — appropriate for a fun currency (this is not
  real-money gambling; no fairness-audit requirement). No finding.
- Logic/service split is right; `casino_logic` is pure and testable.
